# ColorOS Mod

> Module ID: `com.rikumi.colorosmod`
>
> 最低支持: Android 8.0 (API 26) · 最高支持: Android 15 (API 35)

一个针对 ColorOS 的全方位体验增强模块，模拟 Flyme 体验，增加某 Tool 没有的、需要主动定制的功能和界面问题

## 目前主要功能

桌面体验优化

- 增大图标与名称间距
- 减小页面与 Dock 间距
- 缩小图标长按菜单
- 文件夹展开背景透明
- 取消编辑模式背景遮罩
- 彻底隐藏电话本图标
- 彻底隐藏 Gboard 图标
- 彻底隐藏 GhostLock 图标（当然仅 root 下）

控制中心体验优化

- 自定义控制中心/通知中心背景亮度
- 去除控制中心运营商显示
- 隐藏控制中心顶部状态图标簇
- 分离版 Wi-Fi/蓝牙名词单行省略

通知中心体验优化

- 缩小通知静默区域副标题
- 增加通知上下内边距
- 流体云出现时不隐藏电量百分比

隐藏应用相关功能

- 多任务显示已隐藏应用
- 打开隐藏应用文件夹免验证
- 桌面双指张开打开隐藏应用
- 应用隐藏标题显示文件夹名

小窗相关功能

- 多任务隐藏小窗应用
- 悬浮小窗贴边挂机（调试版）
- 横屏应用小窗保持比例

导航与手势

- 调整底部手势区高度
- 调整手势滑动条宽度
- 禁止长按手势条放大效果
- 启用 mBack 功能
- 避免手势区域点击穿透

# ColorOS Mod

> Module ID: `com.rikumi.colorosmod`

一个针对 ColorOS 的全方位体验增强模块，模拟 Flyme 体验，增加某 Tool 没有的、需要主动定制的功能和界面问题

**请同时给 [Xposed 模块仓库](https://github.com/Xposed-Modules-Repo/com.rikumi.colorosmod) 一个 Star！**

## 免责声明

- 本模块由 AI 辅助开发，虽然开发者具有专业开发经验和素质，但仅能保证在开发过程中**绝不包含人工恶意输入、不具有人工恶意行为**。
AI 产生的代码可能无法完全符合开发者预期，请在使用前自行确认。
- 本项目源代码位于 https://github.com/rikumi/coloros-mod/ ，欢迎使用前进行代码审查，并通过源码自行构建 Debug APK。
- 本项目在 OPPO Find X8s 上进行测试，其它机型未进行充分测试，理论适配 ColorOS/OxygenOS/RealmeUI 的 Android 16 版本。
- **改机有风险，和其它模块一样，请勿在未备份的主力机上贸然使用。**

## 目前主要功能

### 桌面

#### 桌面布局

- 增加图标与名称间距
- 调整抽屉图标大小与间距（实验性）
- 字母索引滚动定位
- 减小页面与 Dock 间距
- 取消编辑模式背景遮罩
- 弱化桌面个性化页面背景
- 隐藏桌面图标更新圆点

#### 长按菜单

- 禁用桌面长按二级菜单
- 缩小图标长按菜单
- 长按菜单背景动态模糊
- 自定义长按菜单背景亮度

#### 文件夹

- 文件夹展开背景透明
- 调整文件夹动画持续时间

### 控制中心

#### 通控中心通用设置

- 自定义背景亮度
- 自定义背景模糊半径
- 自定义背景缩小幅度
- 控制中心隐藏运营商
- 隐藏顶部状态图标簇
- 分离版左右平移切换

#### 控制中心设置

- Wi-Fi / 蓝牙名称单行省略
- 无媒体播放时隐藏播放控件
- 分离控制中心空缺位置用磁贴补位
- 调整长形磁贴圆角比例
- 合并版时间日期固定单行
- 音量条显示切换降噪模式图标

#### 合并控制中心现代化

- 合并通控中心前两磁贴采用空心激活态
- 合并通控中心开启全新焕彩样式
- 合并通控中心保持宽高比例
- 调整合并控制中心栏间距
- 合并通控中心磁贴改为四列
- 合并通控中心设置按钮旋转
- 合并通控中心修复磁贴区缩放动画
- 合并通控中心修复二次下拉动画裁切
- 合并通控中心允许双指下拉直接展开
- 允许激活态叠加轮廓光
- 自定义控制中心激活态颜色

### 通知中心与状态栏

#### 通知中心设置

- 通知左滑直接清除
- 通知下滑展开
- 缩小通知静默区域副标题
- 增加通知上下内边距

#### 状态栏设置

- 合并双卡信号
- 隐藏状态栏电量百分号
- 隐藏状态栏漫游图标
- 信号制式文字
- 状态栏字体
- 状态栏字体字重
- 状态栏歌词
- 流体云歌词（试验性）
- 避让第三方状态栏歌词
- 流体云出现时不隐藏电量百分比

### 锁屏

#### 锁屏行为

- 解锁时关机无需校验密码
- 指纹失败三次内不自动弹出密码
- 密码支持滑动输入
- 密码界面支持侧滑/下滑返回

#### 锁屏视觉

- 取消密码界面控件光效
- 自定义密码界面背景亮度
- 锁屏通知区域下移
- 取消锁屏充电动画

### 隐藏应用

#### 隐藏应用逻辑简化

- 多任务显示已隐藏应用
- 打开隐藏应用文件夹免验证
- 桌面双指张开打开隐藏应用
- 应用隐藏标题显示文件夹名

#### 彻底隐藏应用

- 彻底隐藏所选应用图标
- 查看所选隐藏应用列表并启动应用

### 应用小窗

#### 小窗行为

- 修改小窗数量上限
- 多任务隐藏小窗应用
- 悬浮小窗贴边挂机
- 小窗贴边挂机静音

#### 小窗视觉

- 小窗贴边显示为白色竖条
- 横屏应用小窗保持比例
- 优化小窗贴边位置及最大尺寸
- 缩小分屏及小窗顶部菜单栏高度

### 导航与手势

#### 手势行为

- 增大底部手势区高度
- 启用 mBack
- 避免手势区域点击穿透
- 优化屏幕旋转建议按钮位置
- 修改系统长按超时
- 微调系统动画时长

#### 手势视觉

- 调整手势滑动条宽度
- 禁止手势条动画效果

#### 多任务切换

- 移除省电模式锁定任务限制
- 去除多任务界面背景遮罩
- 多任务隐藏未在运行的应用
- 多任务上划彻底结束进程
- 划掉同应用主任务一并结束附属任务

### 存储管理

#### 不自动创建以下文件夹

- Alarms
- Audiobooks
- Movies
- Notifications
- Podcasts
- Recordings
- Ringtones

### 停用应用

- 停用应用无需输入密码
- 在应用管理中隐藏已停用的应用
- 查看已停用及用户级卸载应用，并导出为脚本

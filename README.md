# ColorOS Mod

> Module ID: `com.rikumi.colorosmod`

一个针对 ColorOS 的全方位体验增强模块，模拟 Flyme 体验，增加某 Tool 没有的、需要主动定制的功能和界面问题

**请同时给 [Xposed 模块仓库](https://github.com/Xposed-Modules-Repo/com.rikumi.colorosmod) 一个 Star！**

## 目前主要功能

### 桌面体验优化

- 增大图标与名称间距
- 减小页面与 Dock 间距
- 取消编辑模式背景遮罩
- 缩小图标长按菜单
- 长按菜单背景动态模糊
- 自定义桌面长按背景亮度
- 文件夹展开背景透明
- 调整文件夹动画持续时间

### 控制中心体验优化

- 自定义通控中心背景亮度
- 自定义通控中心背景模糊半径
- 自定义通控中心背景缩小幅度
- 去除通控中心运营商显示
- 隐藏通控中心顶部状态图标簇
- 分离版通控中心左右平移切换
- 分离版控制中心 Wi-Fi/蓝牙名称单行省略
- OxygenOS 控制中心恢复正常圆角
- 合并版控制中心时间日期固定单行

### 通知中心与状态栏体验优化

- 通知左滑直接清除
- 通知下滑展开
- 缩小通知静默区域副标题
- 增加通知上下内边距
- 状态栏显示歌词
- 流体云出现时不隐藏电量百分比

### 锁屏体验优化

- 解锁时关机无需校验密码
- 密码支持滑动输入
- 密码界面支持侧滑/下滑返回
- 取消密码界面控件光效
- 自定义密码界面背景亮度
- 锁屏通知区域下移

### 隐藏应用相关功能

- 多任务显示已隐藏应用
- 打开隐藏应用文件夹免验证
- 桌面双指张开打开隐藏应用
- 应用隐藏标题显示文件夹名
- 彻底隐藏电话本图标
- 彻底隐藏 Gboard 图标
- 彻底隐藏 GhostLock 图标（当然仅 root 下）

### 小窗相关功能

- 多任务隐藏小窗应用
- 悬浮小窗贴边挂机
- 小窗贴边挂机静音
- 小窗贴变显示为白色竖条
- 横屏应用小窗保持比例
- 优化小窗贴边位置及最大尺寸

### 导航与手势

- 增大底部手势区高度
- 启用 mBack 功能
- 避免手势区域点击穿透
- 恢复原生旋转屏幕按钮位置
- 调整手势滑动条宽度
- 禁止长按手势条放大效果

### 停用应用相关功能

- 停用应用无需输入密码
- 在应用管理中隐藏已停用的应用
- 已停用应用列表备份至脚本
